# Online Banking React App

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open the terminal and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite.

The root route (`/`) opens the Login page. This is a front-end demo: any non-empty username and password will log in. Transaction entries are saved in browser localStorage. No real banking, authentication, or payment processing is connected.
